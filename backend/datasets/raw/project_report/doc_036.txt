Abstract
This project presents the design and implementation of a mobile application that applies paging and context switch to improve accuracy and reduce manual effort. The system was developed using Python and scikit-learn and tested on data collected from sensors installed in the laboratory. Experimental results show that the system performs with acceptable accuracy compared with the existing approach. The report discusses the methodology, implementation, results and limitations of the work.

1. Introduction
In recent years Operating Systems has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using paging.

2. Objectives
- To study existing approaches based on paging.
- To design a system architecture that integrates context switch.
- To implement and test the proposed system.
- To evaluate performance and document the results.
