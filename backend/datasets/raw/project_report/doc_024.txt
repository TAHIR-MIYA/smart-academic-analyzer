Abstract
This project presents the design and implementation of a mobile
application that applies decoder and Karnaugh map to improve
accuracy and reduce manual effort. The system was developed using
Android Studio and Firebase and tested on data collected from
public repositories. Experimental results show that the system
performs faster and more accurately compared with the existing
approach. The report discusses the methodology, implementation,
results and limitations of the work.

1. PROBLEM STATEMENT
The existing system relies on manual effort and does not use
decoder. As a result, users face delays and inconsistent results.
There is a need for a reliable system that applies Karnaugh map
effectively.

2. Objectives
- To study existing approaches based on decoder.
- To design a system architecture that integrates Karnaugh map.
- To implement and test the proposed system.
- To evaluate performance and document the results.

3. IMPLEMENTATION
The system is implemented using Android Studio and Firebase. The
main modules are the input module, the processing module and the
output module. The decoder component was implemented as a separate
class so that it can be tested independently. Screenshots of the
user interface are given in Figure 7.

4. Results and Discussion
The system was tested on 474 sample inputs and produced correct
output in most cases. The results are summarised in Table 7. The
proposed approach performs better than the baseline. Some errors
occurred when the input data was incomplete.

5. FUTURE SCOPE
In future the system can be extended with more data and additional
features. A mobile version and cloud deployment can be developed.
Integration of Karnaugh map may further improve accuracy.

6. Conclusion
The project successfully met its objectives. The system
demonstrates that decoder can be applied effectively to this
problem. The work also highlighted the importance of careful
testing.
