1. Methodology
The methodology follows requirement analysis, design, implementation and testing. The input data is first cleaned and prepared. Then decision tree is applied to extract the required information. Finally cross-validation is used to produce the output which is displayed to the user.

2. Implementation
The system is implemented using Android Studio and Firebase. The main modules are the input module, the processing module and the output module. The decision tree component was implemented as a separate class so that it can be tested independently. Screenshots of the user interface are given in Figure 5.

3. RESULTS AND DISCUSSION
The system was tested on 174 sample inputs and produced correct output in most cases. The results are summarised in Table 5. The proposed approach performs better than the baseline. Some errors occurred when the input data was incomplete.

4. Future Scope
In future the system can be extended with more data and additional features. A mobile version and cloud deployment can be developed. Integration of cross-validation may further improve accuracy.

5. Conclusion
The project successfully met its objectives. The system demonstrates that decision tree can be applied effectively to this problem. The work also highlighted the importance of careful testing.
