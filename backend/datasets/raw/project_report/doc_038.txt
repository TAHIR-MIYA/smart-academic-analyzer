Abstract
This project presents the design and implementation of a decision support system that applies TCP and subnetting to analyse large volumes of data efficiently. The system was developed using Android Studio and Firebase and tested on data collected from college records. Experimental results show that the system performs reliably compared with the existing approach. The report discusses the methodology, implementation, results and limitations of the work.

INTRODUCTION
In recent years Computer Networks has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using TCP.

Objectives
- To study existing approaches based on TCP.
- To design a system architecture that integrates subnetting.
- To implement and test the proposed system.
- To evaluate performance and document the results.

IMPLEMENTATION
The system is implemented using Android Studio and Firebase. The main modules are the input module, the processing module and the output module. The TCP component was implemented as a separate class so that it can be tested independently. Screenshots of the user interface are given in Figure 9.
