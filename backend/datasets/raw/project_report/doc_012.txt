Abstract
This project presents the design and implementation of a automated analysis tool that
applies decision tree and k-means clustering to automate routine tasks. The system was
developed using Python and scikit-learn and tested on data collected from sensors
installed in the laboratory. Experimental results show that the system performs with
acceptable accuracy compared with the existing approach. The report discusses the
methodology, implementation, results and limitations of the work.

1. Introduction
In recent years Machine Learning has become an important part of modern engineering.
Manual processes are slow, error prone and difficult to scale. This project aims to
address these issues by using decision tree.

2. Problem Statement
The existing system relies on manual effort and does not use decision tree. As a
result, users face delays and inconsistent results. There is a need for a reliable
system that applies k-means clustering effectively.

3. Objectives
- To study existing approaches based on decision tree.
- To design a system architecture that integrates k-means clustering.
- To implement and test the proposed system.
- To evaluate performance and document the results.

4. Methodology
The methodology follows requirement analysis, design, implementation and testing. The
input data is first cleaned and prepared. Then decision tree is applied to extract the
required information. Finally k-means clustering is used to produce the output which
is displayed to the user.

5. Implementation
The system is implemented using Python and scikit-learn. The main modules are the
input module, the processing module and the output module. The decision tree component
was implemented as a separate class so that it can be tested independently.

The system was tested on 397 sample inputs and produced correct output in most cases.

7. FUTURE SCOPE
In future the system can be extended with more data and additional features. A mobile
version and cloud deployment can be developed. Integration of k-means clustering may
further improve accuracy.

8. Conclusion
The project successfully met its objectives. The system demonstrates that decision
tree can be applied effectively to this problem. The work also highlighted the
importance of careful testing.
