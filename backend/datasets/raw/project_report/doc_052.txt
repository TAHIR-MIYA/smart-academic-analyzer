1. INTRODUCTION
In recent years Natural Language Processing has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using named entity recognition.

2. Problem Statement
The existing system relies on manual effort and does not use named entity recognition. As a result, users face delays and inconsistent results. There is a need for a reliable system that applies stemming effectively.

3. Objectives
- To study existing approaches based on named entity recognition.
- To design a system architecture that integrates stemming.
- To implement and test the proposed system.
- To evaluate performance and document the results.

4. Methodology
The methodology follows requirement analysis, design, implementation and testing. The input data is first cleaned and prepared. Then named entity recognition is applied to extract the required information. Finally stemming is used to produce the output which is displayed to the user.

5. IMPLEMENTATION
The system is implemented using React and Node.js. The main modules are the input module, the processing module and the output module. The named entity recognition component was implemented as a separate class so that it can be tested independently. Screenshots of the user interface are given in Figure 9.

6. RESULTS AND DISCUSSION
The system was tested on 443 sample inputs and produced correct output in most cases. The results are summarised in Table 9. The proposed approach performs better than the baseline. Some errors occurred when the input data was incomplete.

7. Conclusion
The project successfully met its objectives. The system demonstrates that named entity recognition can be applied effectively to this problem. The work also highlighted the importance of careful testing.
