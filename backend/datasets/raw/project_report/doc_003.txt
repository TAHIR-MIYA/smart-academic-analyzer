Abstract
This project presents the design and implementation of a mobile application that applies
multiplexer and flip-flop to analyse large volumes of data efficiently. The system was
developed using Android Studio and Firebase and tested on data collected from college records.
Experimental results show that the system performs faster and more accurately compared with
the existing approach. The report discusses the methodology, implementation, results and
limitations of the work.

Objectives
- To study existing approaches based on multiplexer.
- To design a system architecture that integrates flip-flop.
- To implement and test the proposed system.
- To evaluate performance and document the results.

Methodology
The methodology follows requirement analysis, design, implementation and testing. The input
data is first cleaned and prepared. Then multiplexer is applied to extract the required
information. Finally flip-flop is used to produce the output which is displayed to the user.
