Abstract
This project presents the design and implementation of a decision support system that applies TF-IDF and stemming to improve accuracy and reduce manual effort. The system was developed using Python and scikit-learn and tested on data collected from public repositories. Experimental results show that the system performs reliably compared with the existing approach. The report discusses the methodology, implementation, results and limitations of the work.

1. Introduction
In recent years Natural Language Processing has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using TF-IDF.

2. OBJECTIVES
- To study existing approaches based on TF-IDF.
- To design a system architecture that integrates stemming.
- To implement and test the proposed system.
- To evaluate performance and document the results.

3. LITERATURE SURVEY
Several researchers have investigated TF-IDF in the context of Natural Language Processing. Earlier work proposed a method based on stemming which improved results on benchmark data. However, most existing work does not address scalability and usability.

4. Methodology
The methodology follows requirement analysis, design, implementation and testing. The input data is first cleaned and prepared. Then TF-IDF is applied to extract the required information. Finally stemming is used to produce the output which is displayed to the user.

5. IMPLEMENTATION
The system is implemented using Python and scikit-learn. The main modules are the input module, the processing module and the output module. The TF-IDF component was implemented as a separate class so that it can be tested independently. Screenshots of the user interface are given in Figure 9.

6. RESULTS AND DISCUSSION
The system was tested on 473 sample inputs and produced correct output in most cases. The results are summarised in Table 9. The proposed approach performs better than the baseline. Some errors occurred when the input data was incomplete.

7. Future Scope
In future the system can be extended with more data and additional features. A mobile version and cloud deployment can be developed. Integration of stemming may further improve accuracy.

8. Conclusion
The project successfully met its objectives. The system demonstrates that TF-IDF can be applied effectively to this problem. The work also highlighted the importance of careful testing.
