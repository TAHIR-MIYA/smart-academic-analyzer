1. Objectives
- To study existing approaches based on agile methodology.
- To design a system architecture that integrates waterfall model.
- To implement and test the proposed system.
- To evaluate performance and document the results.

2. Literature Survey
Several researchers have investigated agile methodology in the context of Software Engineering. Earlier work proposed a method based on waterfall model which improved results on benchmark data. However, most existing work does not address scalability and usability.

3. Implementation
The system is implemented using Java and MySQL. The main modules are the input module, the processing module and the output module. The agile methodology component was implemented as a separate class so that it can be tested independently. Screenshots of the user interface are given in Figure 6.

4. Future Scope
In future the system can be extended with more data and additional features. A mobile version and cloud deployment can be developed. Integration of waterfall model may further improve accuracy.

5. Conclusion
The project successfully met its objectives. The system demonstrates that agile methodology can be applied effectively to this problem. The work also highlighted the importance of careful testing.
