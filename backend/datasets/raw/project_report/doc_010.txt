Abstract
This project presents the design and implementation of a monitoring system that applies stack and graph traversal to improve accuracy and reduce manual effort. The system was developed using React and Node.js and tested on data collected from public repositories. Experimental results show that the system performs faster and more accurately compared with the existing approach. The report discusses the methodology, implementation, results and limitations of the work.

1. INTRODUCTION
In recent years Data Structures has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using stack.

2. Problem Statement
The existing system relies on manual effort and does not use stack. As a result, users face delays and inconsistent results. There is a need for a reliable system that applies graph traversal effectively.

3. Objectives
- To study existing approaches based on stack.
- To design a system architecture that integrates graph traversal.
- To implement and test the proposed system.
- To evaluate performance and document the results.

4. Methodology
The methodology follows requirement analysis, design, implementation and testing. The input data is first cleaned and prepared. Then stack is applied to extract the required information. Finally graph traversal is used to produce the output which is displayed to the user.

5. Implementation
The system is implemented using React and Node.js. The main modules are the input module, the processing module and the output module. The stack component was implemented as a separate class so that it can be tested independently. Screenshots of the user interface are given in Figure 6.

6. Results and Discussion
The system was tested on 471 sample inputs and produced correct output in most cases. The results are summarised in Table 6. The proposed approach performs better than the baseline. Some errors occurred when the input data was incomplete.

7. Future Scope
In future the system can be extended with more data and additional features. A mobile version and cloud deployment can be developed. Integration of graph traversal may further improve accuracy.

8. CONCLUSION
The project successfully met its objectives. The system demonstrates that stack can be applied effectively to this problem. The work also highlighted the importance of careful testing.
