Abstract
This project presents the design and implementation of a decision support system that applies overfitting and decision tree to improve accuracy and reduce manual effort. The system was developed using Android Studio and Firebase and tested on data collected from public repositories. Experimental results show that the system performs reliably compared with the existing approach. The report discusses the methodology, implementation, results and limitations of the work.

1. Introduction
In recent years Machine Learning has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using overfitting.

2. Problem Statement
The existing system relies on manual effort and does not use overfitting. As a result, users face delays and inconsistent results. There is a need for a reliable system that applies decision tree effectively.

3. Objectives
- To study existing approaches based on overfitting.
- To design a system architecture that integrates decision tree.
- To implement and test the proposed system.
- To evaluate performance and document the results.

4. Literature Survey
Several researchers have investigated overfitting in the context of Machine Learning. Earlier work proposed a method based on decision tree which improved results on benchmark data. However, most existing work does not address scalability and usability.
