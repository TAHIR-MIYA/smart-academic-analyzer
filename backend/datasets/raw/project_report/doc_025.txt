Abstract
This project presents the design and implementation of a automated analysis tool that applies DNS and subnetting to analyse large volumes of data efficiently. The system was developed using Python and Flask and tested on data collected from user surveys. Experimental results show that the system performs reliably compared with the existing approach. The report discusses the methodology, implementation, results and limitations of the work.

1. Introduction
In recent years Computer Networks has become an important part of modern engineering. Manual processes are slow, error prone and difficult to scale. This project aims to address these issues by using DNS.

2. Objectives
- To study existing approaches based on DNS.
- To design a system architecture that integrates subnetting.
- To implement and test the proposed system.
- To evaluate performance and document the results.

3. Literature Survey
Several researchers have investigated DNS in the context of Computer Networks. Earlier work proposed a method based on subnetting which improved results on benchmark data. However, most existing work does not address scalability and usability.

4. Methodology
The methodology follows requirement analysis, design, implementation and testing. The input data is first cleaned and prepared. Then DNS is applied to extract the required information. Finally subnetting is used to produce the output which is displayed to the user.
