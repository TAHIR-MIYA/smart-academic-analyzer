Abstract
This project presents the design and implementation of a mobile application
that applies isothermal process and first law of thermodynamics to analyse
large volumes of data efficiently. The system was developed using Python
and scikit-learn and tested on data collected from user surveys.
Experimental results show that the system performs with acceptable accuracy
compared with the existing approach. The report discusses the methodology,
implementation, results and limitations of the work.

1. Introduction
In recent years Thermodynamics has become an important part of modern
engineering. Manual processes are slow, error prone and difficult to scale.
This project aims to address these issues by using isothermal process.

2. Problem Statement
The existing system relies on manual effort and does not use isothermal
process. As a result, users face delays and inconsistent results. There is
a need for a reliable system that applies first law of thermodynamics
effectively.

3. Objectives
- To study existing approaches based on isothermal process.
- To design a system architecture that integrates first law of
thermodynamics.
- To implement and test the proposed system.
- To evaluate performance and document the results.

4. Implementation
The system is implemented using Python and scikit-learn. The main modules
are the input module, the processing module and the output module. The
isothermal process component was implemented as a separate class so that it
can be tested independently. Screenshots of the user interface are given in
Figure 6.

5. Conclusion
The project successfully met its objectives. The system demonstrates that
isothermal process can be applied effectively to this problem. The work
also highlighted the importance of careful testing.
