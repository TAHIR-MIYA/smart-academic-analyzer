Learning objectives

Code Review:
Code review is a systematic examination of source code by peers to find defects and improve quality. A common mistake is to confuse code review with UML diagram. Note that code review depends on the assumptions made about the problem. The main advantage of code review is that it is simple to understand and efficient in practice.

Uml Diagram
Uml diagram is a standard visual notation used to model the structure and behaviour of software. Note that UML diagram depends on the assumptions made about the problem. This idea is widely used in real world systems.

Requirements Specification
Requirements specification is a document that describes what the software must do and the constraints it must satisfy. The main advantage of requirements specification is that it is simple to understand and efficient in practice.

Key points
- Remember the definition of code review.
- Uml diagram is related to requirements specification.

Summary
In this unit we studied code review, UML diagram and requirements specification. These ideas form the foundation for further topics in Software Engineering.
