LECTURE NOTES - DATABASE MANAGEMENT SYSTEMS

Transaction:
Transaction is a sequence of database operations that must be executed as a single logical unit. For example, consider a small case in Database Management Systems where transaction is applied step by step.

Sql Join:
Sql join is an operation that combines rows from two or more tables based on a related column. For example, consider a small case in Database Management Systems where SQL join is applied step by step.

Indexing
Indexing is a structure that speeds up the retrieval of rows by searching on selected columns. In practice, indexing is combined with deadlock to solve larger problems. A common mistake is to confuse indexing with deadlock.

Primary Key
Primary key is a column or set of columns that uniquely identifies every row in a table. For example, consider a small case in Database Management Systems where primary key is applied step by step. In practice, primary key is combined with deadlock to solve larger problems.

Key points
- Remember the definition of transaction.
- Sql join is related to primary key.

Summary
In this unit we studied transaction, SQL join, indexing and primary key. These ideas form the foundation for further topics in Database Management Systems.
