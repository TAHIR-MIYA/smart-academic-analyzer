Computer Networks.
Tcp is a connection oriented transport protocol that provides reliable ordered delivery of data.
Ip addressing is the scheme used to identify every host and network on the internet.
Routing is the process of selecting the best path for packets to travel between networks.
Subnetting is the division of a large network into smaller logical networks.
Dns is a distributed system that translates domain names into IP addresses.
Firewall is a security device that filters incoming and outgoing traffic according to rules.
Congestion control is a set of mechanisms that prevent too much data from overloading the network.
